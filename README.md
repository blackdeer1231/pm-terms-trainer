# PM Terms Trainer

PWA для изучения терминов Product Manager и подготовки к собеседованию в gamedev.

Функции: карточки, мнемоники, категории, поиск, тесты по 10 вопросов, отметки «знаю / повторить», статистика и офлайн-режим.

## Установка на планшет

После публикации через GitHub Pages:
- iPad/iPhone: Safari → Поделиться → **На экран Домой**.
- Android/Chrome: меню → **Установить приложение** / **Добавить на главный экран**.

Прогресс хранится локально на устройстве.
